## Featured projects

### REWIND v5
[REWIND](https://github.com/strangedoctor073-alt/Rewind) is my flagship desktop software project: a local-first Windows time machine and productivity application focused on activity history, workspace recovery, universal undo, browser interaction recording, privacy-conscious timeline tracking, encrypted recovery vaults, and automation exports.

The [v5 release](https://github.com/strangedoctor073-alt/Rewind/releases/tag/v5) includes:
- Windows desktop distribution and installer
- Chrome extension for browser interaction capture
- browser automation and macro export workflows
- focus analytics and productivity telemetry
- local AI-assisted daily standup reporting

The release notes report 328 automated tests across 47 Vitest files, with clean lint and TypeScript checks. Those are release-reported results and are not independently verified here.
