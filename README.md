## Featured projects

### AI PR Reviewer
[AI PR Reviewer](https://github.com/strangedoctor073-alt/ai-pr-reviewer) is a GitHub Action that reviews pull requests using AI-backed findings, deterministic static-analysis fallback, defensive prompt architecture, and structured reporting.

Highlights:
- Multi-provider review engine with Claude/OpenAI/Gemini-compatible endpoints
- Repo-aware context analysis and bounded diff review
- Stable PR comment synchronization and fix verification
- Secret redaction, prompt-injection screening, and review safety guardrails
- Structured JSON reports, health scoring, and dashboard integrations

### Rewind
[Rewind](https://github.com/strangedoctor073-alt/Rewind) is a local-first desktop and browser time machine for recording, replaying, and resurrecting user activity without sending data to the cloud.

Highlights:
- Electron-based desktop app with universal undo and app/window resurrection
- Browser interaction recording via Chrome MV3 extension
- Local SQLite-backed timeline and search layer
- Privacy-focused architecture with no keylogging and no cloud dependency
- CLI, daemon, extension, and desktop workflows in one product
